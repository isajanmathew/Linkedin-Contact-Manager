Chrome Extension · Manifest V3

LinkedIn Contact Saver

Captures LinkedIn profiles into chrome.storage.local instantly, then syncs them to Supabase in the background over Realtime.

Load the extension

  1. Run npm run build:extension to assemble the dist/ folder.
  2. Open chrome://extensions.
  3. Enable Developer mode (top right).
  4. Click Load unpacked and select the dist/ folder.
  5. Open the side panel on any linkedin.com/in/… profile.

First-run setup

  • Open the side panel and expand Sync settings.
  • Paste your device key — the shared secret that scopes your rows in Supabase.
  • Everything else works offline; pending changes flush automatically once reachable.
