Chrome Extension · Manifest V3

LinkedIn Contact Saver

Captures LinkedIn profiles into chrome.storage.local instantly, then syncs them to Supabase in the background over Realtime.

Load dist/, never extension-src/

  • extension-src/ holds source modules only — it has no manifest.json, so Chrome reports “Manifest file is missing or unreadable”.
  • The loadable extension is assembled into dist/ by the build script.

Build and load

  1. Run npm install (or bun install).
  2. Run npm run build:extension to assemble the dist/ folder.
  3. Open chrome://extensions.
  4. Enable Developer mode (top right).
  5. Click Load unpacked and select the dist/ folder.
  6. Open the side panel on any linkedin.com/in/… profile.

Prefer a pre-built zip?

  • Download it, unzip it, then Load unpacked the unzipped folder.
  • Available only when the build step packaged it with your Supabase credentials.

First-run setup

  • Open the side panel and expand Sync settings.
  • Paste your device key — the shared secret that scopes your rows in Supabase.
  • Everything else works offline; pending changes flush automatically once reachable.
